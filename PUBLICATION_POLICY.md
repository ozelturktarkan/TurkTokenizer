# Public repository boundary

The public repository contains source code, public upstream provenance, architecture contracts, aggregate research decisions, and reproduction guidance.

The following remain in the project Library or local research storage and are intentionally not published:

- raw or derived corpus files;
- sentence- and surface-level examples derived from corpora;
- exact local corpus hashes beyond public upstream Git blob identities;
- split inventories and sealed-validation sizes or hashes;
- serialized morphology lattices, consensus maps, and dataset packages;
- model checkpoints, optimizer state, hard-negative caches, and live logs;
- detailed internal audit artifacts when an aggregate public summary is sufficient.

This boundary protects evaluation integrity and third-party data obligations without hiding the code, architecture, aggregate results, or falsifiable quality gates.
